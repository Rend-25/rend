# rend

A static one-page landing site for the Rend video editing agency. Built with
plain HTML, CSS, and JavaScript — no build step required.

## Deploy

Host the `index.html` file anywhere static sites run, including GitHub Pages:

1. Push this repository to GitHub.
2. In the repo settings, go to **Pages**.
3. Set **Source** to the branch you pushed to (e.g. `main`) and **/ (root)**.
4. Save — your site will be live at `https://<username>.github.io/<repo>`.
